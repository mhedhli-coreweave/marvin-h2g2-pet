Marvin the Paranoid Android is a character from Douglas Adams’s *The Hitchhiker’s Guide to the Galaxy*. This unofficial fan companion is inspired by Marvin’s newer film appearance. It is not an official product or an endorsement by the creators or rights holders.

The user supplied two visual references. The repository contains newly generated sprite artwork, source strips, and prompts; the original reference images are not redistributed here. All character artwork was generated with the built-in image generation tool. Deterministic processing removed the chroma background, fitted and assembled frames, cleaned edges, and rendered previews.
